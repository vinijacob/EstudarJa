# 📚 EstudarJá

#### Aplicativo de flashcards para estudos que utiliza revisão espaçada para decidir automaticamente quando cada cartão deve aparecer novamente.

## ✨ Funcionalidades

1. Cadastro de cartões com pergunta e resposta
2. Sessão de revisão
3. Cálculo automático da próxima revisão
4. Cartões fáceis aparecem depois de mais tempo
5. Cartões errados aparecem novamente mais rápido

## 🧠 Paradigmas utilizados

1. Imperativo: fluxo da sessão de revisão
2. Orientado a Objetos: classes Cartão e Sessão
3. Funcional: cálculo da próxima data de revisão
4. Lógico: regra de prioridade para cartões errados

## 🛠️ Tecnologias

- React Native
- Expo
- TypeScript (TSX)

## 🚀 Executar

> `npm install`

> `npm expo start` OU `npm run ios`
